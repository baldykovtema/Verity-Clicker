# Verity Clicker — сайт

Статический сайт для GitHub Pages. Источник публикации: ветка `main`, папка `/`.

Кнопки скачивания ведут на последнюю версию GitHub Releases репозитория `baldykovtema/Verity-Clicker`. К выпуску `v1.1.0` нужно прикрепить файлы с точными именами:

- `Verity-Clicker-Windows-1.1.0.exe`
- `Verity-Clicker-Mac-1.1.0.dmg`
- `Verity-Clicker-Windows-folder-1.1.0.zip`

Windows EXE (109 МБ) и ZIP (160 МБ) превышают лимит обычных файлов GitHub и должны быть в Releases. Видео и изображения уже лежат в `assets/` и включены в сайт.
